# Roadmap

Plans, not promises. Open an issue to ask for something.

## Next

- A web demo to try in the browser
- Media keys and window snapping on Windows
- An endless Instant Mix
- Streaming quality setting for slow connections
- Flatpak on Flathub
- macOS

## Later

- Beat-matched crossfade and DJ-style cue points

## Not planned

- Offline downloads, equalizer, visualizer, tray icon
- Internet radio, merged libraries, transcoding
- Volume leveling: gain tags are too often wrong
- Song change notifications: media controls already show the song

Details behind these plans: [design notes](design.md#planned-work).
